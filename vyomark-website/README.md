# Vyomark Digital Solutions Website

## Run locally

1. Open a terminal in this folder:
   ```bash
   cd vyomark-website
   ```
2. Start a local server (recommended):
   ```bash
   python3 -m http.server 8080
   ```
3. Open: `http://localhost:8080`

> You can also open `index.html` directly, but using a local server is better for consistent behavior.
